## Featured Projects

### [Inquestra](https://inquestra.org) — Local-First Electronic Research Notebook
An open, browser-based Electronic Lab Notebook (ELN) for wet-lab biology, synthetic chemistry, and physical bench instrumentation.
- **Local-First & Air-Gapped:** Experimental trials and protocols persist locally in browser IndexedDB with zero cloud lock-in.
- **Native Hardware DAQ:** Direct real-time sensor streaming via the W3C Web Serial API (Arduino, ESP32, bench meters) without installing driver bloat.
- **Scientific Primitives:** SMILES molecular rendering, oligonucleotide melting temperature ($T_m$) calculators, KaTeX math, and cryptographic SHA-256 audit trails.
- **Live Platform:** [inquestra.org](https://inquestra.org) · **Repository:** [kaleb973/Inquestra](https://github.com/kaleb973/Inquestra)

### [GBMDevice](https://github.com/kaleb973/GBMDevice) — Exploratory Glioblastoma Breath Biosensor
A portable, low-cost breath-based volatile organic compound (VOC) detection device for exploratory glioblastoma recurrence monitoring.
- Utilizes embedded gas sensing and microcontroller telemetry to detect minute acetone spikes in synthetic breath environments.
- Designed to investigate non-invasive, accessible screening methods for oncology monitoring.
- Written in C++ for embedded platforms.

### [MiniMac](https://github.com/kaleb973/MiniMac) — Dedicated Bench Macro Controller
Custom firmware in C for an external embedded keypad used for one-touch laboratory actuation, screen capture documentation, and high-speed bench shortcuts.
